# Apple Music Desktop Clone

A cross-platform Apple Music inspired desktop application built with Flutter.

This project recreates the Apple Music desktop experience with playlist browsing, music playback, reactive player controls, and adaptive audio streaming support.

# Features

- Modern Apple Music inspired desktop UI
- Playlist browsing
- Audio playback support
- Song queue navigation
- Previous / Next controls
- Seekbar and volume controls
- Reactive playback state management
- Adaptive streaming playback
- Windows desktop support
- Built using Flutter desktop

---

# Tech Stack

- Flutter
- Dart
- GetX
- just_audio

---

# Architecture

The app uses reactive state management with GetX and asynchronous playback handling using just_audio.

Main components include:

- Playlist browsing system
- Streaming data parser
- Audio playback controller
- Reactive UI updates
- Queue management

---

# Challenges Solved

- Implemented adaptive audio streaming playback
- Managed asynchronous player state updates
- Prevented race conditions during rapid song switching
- Built responsive desktop layouts
- Synced playback progress with UI state
